# ESTEBAN OSSES — Portfolio profesional

Portfolio digital mobile-first para compartir por WhatsApp.

## Publicación
1. Repository: `eliasmartinezcultural-glitch/PORTAFOLIO-OSSES-ESTEBAN`
2. Branch: `main`
3. GitHub → Settings → Pages
4. Source: Deploy from a branch
5. Branch: `main` / `(root)`
6. Save.

GitHub generará una URL HTTPS del tipo:
`https://eliasmartinezcultural-glitch.github.io/PORTAFOLIO-OSSES-ESTEBAN/`

## WhatsApp
El HTML ya contiene Open Graph y Twitter Card. Para obtener la preview gráfica personalizada, subir `esteban-osses-share-card.jpg` a la raíz del repositorio y mantener:
`og:image = esteban-osses-share-card.jpg`
Cuando se publique, comprobar la preview desde otro chat/dispositivo porque WhatsApp puede cachearla.
